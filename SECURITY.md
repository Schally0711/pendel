# Security policy

## Supported versions

Pendel is in beta. Security fixes are made for the latest release only (currently 0.9.x).

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately via
[GitHub Security Advisories](https://github.com/Schally0711/pendel/security/advisories/new)
(*Security → Report a vulnerability*). Please include the version, a description, and steps to reproduce.

You will get an answer within a few days. Once a fix is released, the advisory is published and you are credited
if you want.

---

**Deutsch:** Sicherheitslücken bitte nicht als öffentliches Issue melden, sondern privat über
[GitHub Security Advisories](https://github.com/Schally0711/pendel/security/advisories/new). Unterstützt wird
jeweils die neueste Version.
